# soundlog 输出格式约定（v1）

状态：时间轴与转写格式已实现；环境事件 JSON 已实现合成数据路径，SoundAnalysis 及真实录音效果待 Mac 验证。示例时间均为合成数据，不对应实际录音。

## 共同时间轴

- 输入文件名主体必须是 14 位 ASCII 数字 `yyyyMMddHHmmss`；日期和钟表字段必须有效。文件名只给出录音开始时的钟表读数，不附加或推断时区。
- 所有模块以原录音起点为零点，保存 `start_offset_seconds` 和 `end_offset_seconds`。分块结果必须加回分块在原录音中的起点；静音、未识别和未处理区间不能压缩。
- 可读时间戳格式为 `yyyy-MM-dd'T'HH:mm:ss.SSS`，不带 `Z` 或 UTC 偏移。它由文件名钟表时间加原始偏移得到；偏移秒数是计算依据，时间戳是显示字段。
- 区间必须是有限数值、起点不小于零、终点严格大于起点，并且不超出已知音频时长。区间可重叠；同一时间轴上的记录按起点非递减排列。

## 一次运行的结果

运行产物采用 UTF-8 JSON，顶层包含 `schema_version`、`run_id`、`source`、`engine`、`coverage` 和模块结果。`source`记录输入文件名、SHA-256、时长及`recording_start_local`；`engine`记录引擎、版本和实际参数。运行清单需区分已处理覆盖范围、命中文字范围、失败区间和未处理区间。

转写入口的`raw.json`字段包括`schemaVersion`、`sourcePath`、`sourceSHA256`、`engine`、`parameters`、`recordingStartLocal`、`segments`、`coverage`、`textRanges`、`status`和`accuracyAssessment`。`coverage`表示已处理覆盖范围，`textRanges`仅由含非空文字的片段区间生成；无字区间仍属于已覆盖范围。`status`为`completed_with_text`或`completed_no_text`，并附有“文字准确性未评估”的边界说明。用户可读稿由raw结果渲染，单独保存为`transcript.md`。JSON产物通过临时文件加原子rename落盘。每个源文件的`status.json`原子保存`state`（`completed_with_text`、`completed_no_text`或`failed`）、可选`error`和`fingerprint`（源SHA-256、引擎、参数）。仅成功状态且`raw.json`存在时可复用；失败、指纹变化或产物缺失均重跑。

### 文字片段

每项包含原音频偏移区间、对应钟表时间、原文、来源引擎及可用的置信信息。原始引擎结果与可读稿分开保存；置信度只有在引擎提供时才写入。

### 声音分类窗口与合并事件

`sound-events.json` 顶层含 `schemaVersion`、`sourcePath`、`sourceSHA256`、`recordingStartLocal`、`engine`、`parameters`、`windows`、`events`、`windowBoundaryCaveat`、`inferenceBoundary`。参数包含 `confidenceThreshold`、`minimumEventDurationSeconds`、`mergeGapSeconds`。每个窗口保留相对起止秒、`classificationStatus`（`classified`/`unknown`）及全部 `{category, confidence}` 候选；低于阈值的候选仍留在原窗口，若没有任何达阈值候选则标记`unknown`并可生成 unknown 事件。事件含类别、相对起止、`sourceWindowIndices`，以及 `absoluteStartLocal`/`absoluteEndLocal`；索引指回原始窗口，因此可回查候选。各类别分别合并，允许同一时段出现重叠事件。分类窗口边界不作为真实事件精确起止；候选不自动确认地点、活动或现场/外放来源。

CLI 可用重复的 `--param key=value` 设置这三个参数：`confidenceThreshold` 范围为 0–1，`minimumEventDurationSeconds` 与 `mergeGapSeconds` 为非负秒数。非数字、非有限数字、越界值及未知参数均会报错。

示意字段：

```json
{
  "schemaVersion": 1,
  "parameters": { "confidenceThreshold": 0.3, "minimumEventDurationSeconds": 0.5, "mergeGapSeconds": 0.5 },
  "windows": [{ "startOffsetSeconds": 0.0, "endOffsetSeconds": 1.0, "candidates": [{ "category": "rain", "confidence": 0.82 }] }],
  "events": [{ "category": "rain", "startOffsetSeconds": 0.0, "endOffsetSeconds": 1.0, "sourceWindowIndices": [0], "absoluteStartLocal": "2024-02-29T23:59:59.000", "absoluteEndLocal": "2024-03-01T00:00:00.000" }]
}
```

### 说话人片段

每项保留匿名 `speaker_id`（无法判断时为空）、原音频偏移区间和模型来源。重叠允许并存；没有可用文字的语音区间仍保留。姓名与跨文件身份匹配属于后续可选层，不放入默认匿名结果。

## 合成示例

输入 `20240229235959.mp3`，偏移 `2.0` 秒对应 `2024-03-01T00:00:01.000`。该值是不附时区的钟表时间；不代表 UTC，也不代表某一地区的民用时区。
