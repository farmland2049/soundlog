# 本地功能草稿试验与进度边界

日期：2026-11-13。当前为实验通路，尚未通过真实样本质量验收，不作为全文默认提炼引擎。

## 已有环境与本轮实测

本机已有Ollama及完整Qwen3 8B权重。本轮没有安装依赖或下载模型；临时启动已有服务，仅监听127.0.0.1，服务回执确认cloud disabled。试验后模型已卸载出运行内存，临时服务已停止，没有设置后台常驻。

`scripts/products_local.py` 使用标准库，只连接构造的127.0.0.1地址，绕过系统代理并拒绝重定向；显式检查模型已在本机列出且非远程模型，不拉取模型、不调用外部服务、不自动导入。

## 复现入口

仅在已有本地服务启动、模型已安装、请求已导出的情况下，可运行草稿试验：

```bash
python3 scripts/products_local.py --root /absolute/path/products --request prodreq-已有请求 --model 已安装本地模型 --key 已有块编号
```

不提供key时尝试全部请求块，因此当前质量未通过时不应将此入口作为两天自动批处理默认路径。先限制到测试块。

草稿位于请求库的 `local-drafts/run-.../`，保存原始成功响应、每块结构校验结果和状态，单块最多两次尝试，成功可复用。失败返回非零。当前没有自动语义审核，不能从结构completed推断语义通过。

模型选择的是精简编号，程序据编号填回原句。原句匹配证明引用的确来自输入，不能证明模型摘要正确。覆盖说明只说该句已送入本地模型或被选为证据，明确不冒充人工逐句判断。

## 第一次质量结果

五个已有人审参考的片段：

- 三个测试片段两次尝试后仍有非待办taskState等结构错误；具体话题仅保留在本地忽略产物。
- 一个安排片段虽然结构通过，却漏掉相对期限和条件承诺，误读含糊物品。
- 模糊课程例虽然结构通过，却多次使用“用户”作为匿名片段主语，也没有合理放弃无法理解的知识。

因此该轮质量门槛未通过，草稿未导入，没有据此启动240块全文自动处理。这个结果不是对所有本地模型的泛化结论，也没有把5例混合结构/语义结果当作准确率。

后续可继续改进模型/提示词/结构约束并复测，但不能通过删除校验、默认确认身份或把转述当事实来提高完成率。原记忆工作流的LocalModelAdapter仍为独立的预留接口，本试验未将它替换为生产可用实现。

## 独立的只读进度

```bash
python3 scripts/products.py status --request prodreq-已有请求
```

区分not_started、partial、ready_to_combine和completed；按本请求实际校验导入的核心块计算，导出材料、本地未导入草稿、邻近上下文或其他选段试验不计入。多个分批都到齐但尚未合并时为ready_to_combine；语义评审状态不由机械完成状态推断。

## 复测记录（2026-11-13，第1轮收紧提示词）

为减少结构失败，提示词已收紧为“非actions栏taskState必须null”，未修改校验器；相关测试仍通过。使用同一模型重跑5个已审片段：

- case-07结构通过，但摘要重复且含糊，未选中原句时未按程序要求说明原因，仍使用“用户”作主语；语义不合格。
- case-11与case-24两次尝试后仍只引用邻块上下文。
- case-13两次尝试后待办事实缺少taskState。
- case-21两次尝试后非待办栏仍提交taskState。

结果：**1/5结构通过，4/5失败；本轮质量门槛仍未通过，草稿未导入，仍不启动240块自动处理。**这表明单纯加强提示词不足以让该模型稳定通过现有校验，后续需要更强的结构约束或改用其他模型/处理策略，再复测。

进度边界不变：完整两天请求仍为1/240块、30/5,439条导入；本轮新增内容全部是未导入本地草稿与质量记录。

## 复测记录（2026-11-13，第2轮：单一用途与仅核心原文）

进一步收紧后，5个已审片段结构校验首次全部通过。改动包括：每条事实只允许一个功能标签；本地草稿只送本块核心原文，不再送邻块c编号；明确journal/minutes/learning的taskState必须null；相关8项回归测试通过。

语义复核仍不合格：

- case-07：摘要重复，匿名机器稿主语写成“用户”，计划未拆到待办。
- case-13：遗漏相对期限、条件与明确安排，并误写物品名称。
- case-21：把明确的数量假设举例写成实际发生。
- case-24：把无法听音和含糊课程片段逐句转成多条“提到”式伪信息。

结论：**结构通过不代表语义合格；Qwen3 8B-lowthink仍不能用于240块全文默认提炼。**质量门槛未通过，草稿未导入。后续需要更强的任务拆分、功能标签约束、模糊片段留空规则，或改用其他模型，再复测。
