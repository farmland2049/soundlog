# Soundlog 综合测试与通用 Skill 演进记录

## 1. 项目定位与通用 Skill 愿景

- **项目核心愿景**：构建一套完全本地离线、隐私安全、硬件无关的随身录音智能分析系统。让普通随身录音笔具备乃至超越市面流行 AI 录音硬件（如 Plaud Note、Limitless Pendant、OMI）的核心能力。
- **Agent Skill 演进目标**：本项目最终将封装为一个**标准、通用的 AI Agent Skill**（兼容 Antigravity、Claude Code、Cursor 等主流 AI 协作 Agent），向外部 Agent 暴露高内聚、低耦合的标准 Tool 接口：
  - `soundlog_scan`: 扫描并报告待处理录音箱状态及增量文件。
  - `soundlog_process`: 驱动底层离线引擎完成语音转写、环境音事件提取与说话人候选对齐（50x 实时倍速）。
  - `soundlog_daily_scenes`: 跨录音文件按自然日时序重构生活/工作连续对话场景。
  - `soundlog_memory_extract`: 调用大模型能力，从当日场景切片中提炼原子事实、决策、承诺与实体关系。
  - `soundlog_memory_search`: 基于本地 SQLite 与原子 Markdown 提供混合检索与记忆问答。

## 5. 测试中发现的问题与排错记录 (Test Issues & Fixes)

| 编号 | 涉及组件/环节 | 现象描述与影响 | 根因分析 | 处理措施与状态 |
| :--- | :--- | :--- | :--- | :--- |
| **T-01** | 声学聚类 / 场景重构 | 医院广播叫号（如“内科学14号到2号室就诊”）被聚类为一个单独 speaker，险些误当成主体对话。 | 医院高保真扬声器音量大、清晰度高，被 FluidAudio 聚类为独立说话人。 | **已规范**：大模型分析时结合环境声事件（hall/broadcast 特征）与单向语流，判定为背景广播，不绑定为任何实体。 |
| **T-02** | 播客外放 / 机器转写 | 清晨 AI 播客、英语课程被转写，容易被误认为是持有人当面发言。 | 缺少视频模态时，单纯声学转写无法直接判断是现场讲话还是音响外放。 | **已优化**：依靠环境声标签中的 `music` / `radio`，以及 Layer 3 协议中的 `assertion: reported/uncertain` 进行隔离，禁止提升为 `explicit decision/todo`。 |
| **T-03** | AudioSet 标签映射 | 底层 SoundAnalysis 输出 `whale_vocalization`（鲸鱼叫声）等抽象科研标签。 | AudioSet 训练集特征重叠，衣物摩擦或特定空调通风低频噪声被误归纳为海洋动物。 | **已修复**：`build_daily_scenes.py` 内部引入 `SOUND_LABEL_MAP`，映射为“低频底噪/通风换气”，消除大模型理解困惑。 |
| **T-04** | 批处理幂等性 | 当收件箱中混入已归档过的旧文件（如 11-07、11-08）时，不应重复耗费 50 分钟重新计算。 | 录音文件哈希和 run-manifest 校验机制。 | **已验证**：`SoundlogCLI` 自动检测到已存在的 run-manifest 并完成 sidecar 快速自检，13 个文件在 45 秒内快速完成校验并重归档。 |

## 6. 通用 AI Agent Skill 架构与接口规范设计

为了让本项目未来能无缝作为通用 Skill 被各种 AI Agent（如 Antigravity、Claude Code、Cursor 等）加载与调用，规划如下标准 Skill 规范：

### 6.1 Skill 目录结构规范 (`skills/soundlog/`)
```
skills/soundlog/
├── SKILL.md                 # Agent 核心指令与使用说明
├── scripts/
│   ├── scan.sh              # 快速检查录音收件箱状态
│   ├── process.sh           # 触发底层离线多模态批处理
│   ├── daily_scenes.py      # 按天生成场景剧本
│   └── query_memory.py      # 记忆检索接口
└── references/
    └── memory_protocol.md   # 本地可审计原子记忆规范
```

### 6.2 Agent Tool 接口契约定义

1. **`soundlog_status()`**
   - **功能**：报告当前待处理箱音频数、已归档音频数、最新聚合的自然日区间、记忆库原子条目数。
   - **返回**：`{ "inbox_count": 0, "archived_count": 42, "days_covered": ["2026-11-07" ... "2026-11-12"], "memory_count": 139 }`

2. **`soundlog_process_inbox(mock=false)`**
   - **功能**：一键消费待处理箱录音，完成转写、环境音提取、说话人聚类、归档与跨天场景刷新。

3. **`soundlog_get_daily_scene(date="YYYY-MM-DD")`**
   - **功能**：读取指定日期的全天连续对话场景 Markdown 与关键声学标记，供 Agent 快速阅读并回答用户“我今天做了什么/有什么安排”。

4. **`soundlog_search_memory(query="", date="", type="", entity="")`**
   - **功能**：基于 SQLite 全文检索与原子 Markdown，返回带证据原文的记忆事实与决策。
